SmartAgent Release Package

1. Run install_release.bat first.
2. Confirm Python runtime configuration.
3. Run Edit_workspace.bat to configure workspace and WebGPT links.
4. Run launch_smart_agent.bat to start using the default configured profile.

Release structure:
- agent_core: core runtime
- RemoteAgent: remote communication layer
- smart_agent.py: planner/configuration entry
- config: startup preferences
- python_runtime: Python runtime configuration
