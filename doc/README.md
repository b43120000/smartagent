# SmartAgentv2

SmartAgentv2 專案的簡易說明文件。

## 專案內容

- `source/`：專案原始碼目錄。
- `config/`：設定檔目錄。
- `install_smart_agent/launchers/install_smart_agent.bat`：安裝相關批次檔。
- `launch_remote_agent.bat`：Remote Agent 啟動相關批次檔。
- `Edit_workspace.bat`：工作區設定相關批次檔。
- `update.bat`：更新相關批次檔。

## 使用提醒

請先確認執行環境與設定，再依需求使用對應的批次檔。詳細操作與參數以專案中的實際程式及設定為準。
